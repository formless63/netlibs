# @formless63/viewer-model

`MeshViewer` (STL, OBJ, PLY, OFF, 3MF) and `GltfViewer` (GLB, glTF).

Set `configureGltf({ dracoDecoderLocation })` to avoid model-viewer's CDN download for compressed models.

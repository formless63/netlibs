# @formless63/viewers

Every file viewer behind one lazy registry.

```tsx
import '@formless63/viewers/styles.css';
import { createDefaultRegistry, FileViewer, ViewerProvider } from '@formless63/viewers';
```

`@formless63/viewers/registry` is the registry alone, for servers.
